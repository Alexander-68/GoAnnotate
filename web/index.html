GoAnnotate
Visualize and annotate YOLO11 detections and 17-keypoint pose labels directly against your local image set.

Where to start

Click the Load button (top-right) to select your Images and Labels directories.

Use the Browse buttons to open a folder picker overlay. It starts from the path already in each field and lets you confirm the selected folder.

Labels auto-suggest matches `images_*` to `labels_*` and `image-*` to `label-*` when the paths follow that naming.

If a selected folder has no images or labels, the Load flow asks whether to revise paths or continue with what was found.

Changes are saved automatically as soon as the image is changed. Undo works only within unsaved changes.
