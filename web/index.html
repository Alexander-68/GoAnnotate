GoAnnotate
Visualize and annotate YOLO11 detections plus YOLO11 (17-keypoint) and MPII (16-keypoint) pose labels directly against your local image set. Each dataset has a Task (Auto, Detection, Pose, Pose_mpii) shown in the Status panel.

Getting Started
  • Click Load (top-right) to select Images and Labels directories.
  • Changes save automatically on image switch. Undo available for unsaved changes (up to 512 actions per image).
  • Status panel File and Folder lines show the last 36 characters to keep the panel compact.
Task
  • Detection: bounding boxes only (keypoints are disabled).
  • Pose: bounding boxes + 17 keypoints. Pose_mpii: bounding boxes + 16 keypoints.
  • Once set, the Task stays fixed until you Load a new dataset.

Delete

Nothing is selected. Choose what to delete.

Deleting the image moves it and its matching label file into `deleted` subfolders.

Mark Review

Set review status to Done or TODO for the current image or the entire folder.

Crop Aspect

Auto-fit a crop around all annotations with up to 10% padding (reduced near borders). Choose an aspect ratio (1:1, 1:2, 2:3, 3:4, 16:9).

Restore Labels

Undo is empty. Restore the initial or latest saved labels for this image.

Restores are loaded into the editor and saved only when you save or switch images.
