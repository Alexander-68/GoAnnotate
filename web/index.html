GoAnnotate
Visualize and annotate YOLO11 detections plus YOLO11 (17-keypoint) and MPII (16-keypoint) pose labels directly against your local image set.

Getting Started
  • Click Load (top-right) to select Images and Labels directories.
  • Use Browse to pick folders. Single-click enters, double-click selects.
  • Labels are auto-matched if naming follows `images` / `labels` convention.
  • Changes save automatically on image switch. Undo available for unsaved changes (up to 512 actions per image).
  • Image switches keep the previous frame visible while the next loads (no blank flash).
Pose Formats
  • YOLO11 pose: 17 keypoints.
  • MPII pose: 16 keypoints with ankle -> knee -> hip -> pelvis -> hip -> knee -> ankle, pelvis -> thorax, thorax -> shoulders -> elbows -> wrists, and thorax -> upper neck -> head top.
  • Format is auto-detected per label line by keypoint triplet count.
